## TIPS

- IDE（Integrated Development Environment，集成开发环境）是写代码用的那套软件：不只是记事本式的编辑器，还带调试、终端、Git、插件等常用工具。新版 Antigravity 改成以 Agent 为主；若仍要传统代码编辑器，可另外下载名为 Antigravity IDE 的应用。
- `context deadline exceeded` 表示程序向某个接口发请求时超时、没有在时限内完成。Antigravity 登录时若出现 `Post "https://oauth2.googleapis.com/token": context deadline exceeded`，通常不是密码错误，而是访问 Google 登录接口超时（网络、代理/VPN 不稳定，或登录窗口过期）。可检查能否访问 Google 后重试，或换一个 Google 账号继续。
- Codex 是 OpenAI 的编程 agent，挂在同一个 ChatGPT 账号和套餐下面，但不是同一个产品。ChatGPT 里现在分 Chat（日常对话）和 Work（做文档、表格、调研这类较长任务）；Codex 专门写代码、改仓库、跑命令和看 diff。从 2026 年 7 月起，原来独立的 Codex 桌面应用已经并进新的 ChatGPT 桌面应用，两边历史分开。本机 `codex` CLI、编辑器插件和网页版是同一套 agent，用 ChatGPT 登录，用量算在 ChatGPT 套餐里；也可以改用 API key，按 API 计费。Codex Cloud（云端机器跑任务）要付费套餐，Free / Go 没有。
- Code Bench（这里指 Z.ai Code Bench）是智谱自己做的内部编程评测，用来看编程 agent 在接近真实开发场景里的综合表现：把模型放到复杂的本地开发环境中，按不同思考档位执行端到端任务，并同时看任务完成率和更细的清单正确率。它不是 SWE-Bench 那种公开、可复现的通用榜单，所以「GLM-5.3 比 5.2 在 Code Bench 上高约 50%」是官方用这份内部基准公布的相对提升（Max 档完成率约从 23.4% 提到 34.5%），不是第三方公开测出来的分数。
